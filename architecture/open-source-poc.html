Vivolution SBC — Open Edge POC

One provider tenant, two customer tenants, two isolated PBX relays, a separate control plane, and no live PSTN traffic.

Isolation first

FQDN and trusted peer identity establish the tenant. Numbers and user-controlled SIP headers never select a tenant.

Calls outlive the portal

Each edge node runs a signed last-known-good configuration. A portal or database outage must not stop new calls.

HA scope

The alternate node protects new calls. A complete node failure is not expected to migrate an established media session.
